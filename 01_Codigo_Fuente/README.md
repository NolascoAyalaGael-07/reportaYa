# Código fuente

El código completo y actualizado está organizado por responsabilidad en:

- [`../backend/`](../backend/): API en Node.js, Express y TypeScript; autenticación, permisos, reportes, notificaciones y acceso a MySQL.
- [`../frontend/`](../frontend/): aplicación web en React, TypeScript, Vite y Tailwind CSS.

Para instalar y ejecutar los dos proyectos, sigue las instrucciones del [README principal](../README.md#instalación-y-ejecución). Se excluyen del repositorio dependencias instaladas, compilaciones, archivos `.env` y fotografías subidas localmente.
